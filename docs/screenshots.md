## How to capture

1. Open Anki Desktop
2. Find a card via the Browser
3. Use the Preview button (or just Review the card)
4. Use Windows **Snipping Tool** (Win + Shift + S) to capture
5. Save as PNG into `docs/images/`
6. Reference from README:
   ```markdown
   ![Front of der Hund](docs/images/front-der-hund.png)
   ```
